# Schemas used by the tests

## `sarif-schema-2.1.0.json`

The JSON schema of SARIF 2.1.0 (Errata 01), the OASIS Static Analysis Results Interchange Format standard. `tests/sarif-schema.test.js` validates the output of `renderSarifReport` against it.
